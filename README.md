# Assignment-1--Data-Exploration-
In this Excel assignment explores the product dataset to analyse product prices and categorized the products using different excel functions.

In this assignment I have done;
- Calculated the total price of all products using the SUM Function.
- Counted the number of products in the dataset using the COUNT Function.
- Calculated the average product price using the AVERAGE Function.
- Found the minimum and maximum product price using the MIN and MAX Function.
- Categorized products priced $500 or above as "High Price" and others as "Standard Price" using the IF Function.
- Calculated the total price of products in the Electronics category using the SUMIF Function.
- Counted the products priced below $100 using the COUNTIF Function.
- Categorized the day, month, and country code from Product IDs using the LEFT, MID, and RIGHT Functions.
